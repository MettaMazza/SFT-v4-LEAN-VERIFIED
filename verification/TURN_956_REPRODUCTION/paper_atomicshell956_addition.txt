
828. Complete principal shells, generated filling recurrence and periodic closure

The admitted orbit-capacity construction supplies every positive orbit rank r with one central orientation and r-1 complete pairs of boundary orientations. Each orientation retains the two exclusion-distinct labels. Its capacity is therefore
  C(r)=2[1+2(r-1)].
A principal shell n contains each orbit rank One through n exactly once. Define its complete sum by
  S(0)=0 (host accumulator),
  S(n+1)=S(n)+C(n+1).
The first emitted shell is S(1)=2. If S(n)=2n^2, the next complete orbit contributes 2(1+2n)=4n+2, so
  S(n+1)=2n^2+4n+2=2(n+1)^2.
The Lean induction proves this identity for every n; the original first-32 witness is retained alongside it. In particular the first four shell capacities are 2,8,18,32. Boolean, non-integer, nonpositive shell inputs retain the original rejection behavior.

The filling walk is generated from joint cover, not from a table of configurations. For each cover c=2,...,M, visit principal ranks p=1,...,c-1 in order, set r=c-p, and emit (p,r) exactly when r<=p. Thus every emitted cell has 1<=r<=p and p+r=c. The next cover appends its complete row while holding every earlier cell. The accepted cover domain is integer M>=2, excluding Booleans. The source's atomic endpoint is the previously derived floor of inverse alpha, 137, so the closure walk uses M=2*137=274.

Starting with the host accumulator A=0, each emitted (p,r) updates A to A+C(r). Emit a closure precisely at the first cell (1,1) or whenever r=2. Return when the requested positive closure-prefix length has been emitted; a request exceeding the admitted walk retains the original failure. The first cells and their cumulative capacities are
  (1,1):2; (2,1):4; (2,2):10; (3,1):12; (3,2):18;
  (4,1):20; (3,3):30; (4,2):36; (5,1):38; (4,3):48;
  (5,2):54; (6,1):56; (4,4):70; (5,3):80; (6,2):86;
  (7,1):88; (5,4):102; (6,3):112; (7,2):118.
The original rank-two closure rule consequently gives
  Q=(2,10,18,36,54,86,118).
Successive positive differences, using a host origin only for the first subtraction, give
  W=(Q1,Q2-Q1,...,Q7-Q6)=(2,8,8,18,18,32,32).
These are period widths; they are distinct from the complete principal-shell capacities. The implementation generates the walk and accumulates orbit capacities before comparing these output vectors.
