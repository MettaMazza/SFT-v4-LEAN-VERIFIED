REVIEW QUESTION
Does the original reverse-record operation, and its native Lean translation, preserve exactly the predecessor information specified by the source? Please examine the distinction between recording all predecessors and recovering which predecessor supplied a particular output.

SOURCE DOMAIN AND WORKED EXAMPLE
The input is a nonempty ordered list of distinct source strings and a total single-valued map with exactly those source keys. Image order is first occurrence along the source; fibre members retain source order.

For source (aa, ab, ba, bb), let f retain the first letter:
aa -> a; ab -> a; ba -> b; bb -> b.
The six source pairs split into:
closed: (aa,ab), (ba,bb);
retained: (aa,ba), (aa,bb), (ab,ba), (ab,bb).

The reverse record returns:
(a, ("held-predecessor-labels", (aa,ab)))
(b, ("held-predecessor-labels", (ba,bb))).
A singleton fibre instead returns its unique source string. The held list preserves all possible predecessors; it does not select which one supplied an individual output. A retained predecessor label must resolve that choice for reconstruction.

Now compose with g(a)=g(b)=one. All six source pairs close. For any admitted total maps f and g, f(u)=f(v) implies g(f(u))=g(f(v)); thus closed pairs persist and downstream retained pairs are a subset of upstream retained pairs. The paper derives this for arbitrary admitted finite carriers, not only this four-label example.

TRY THE RECORDS BEFORE READING THE PROOFS
A. Count and identify.
For the four-source prefix map above, list all six unordered source pairs in source order. Mark a pair closed when its two images agree and retained otherwise. Now compose with a->one and b->one. Which original pairs remain retained?

B. Recover a particular input.
Suppose the observed image is a and its reverse record holds (aa,ab). Can this record alone distinguish a run that began with aa from one that began with ab? Compare this with the identity map on the same four-source carrier.

C. Preserve the declared order.
Keep the prefix map but supply the source order (bb,aa,ba,ab). What is the image order and what is the order within each predecessor fibre? Does changing this enumeration make the prefix map reversible?

WORKED ANSWERS
A. The pairs are (aa,ab), (aa,ba), (aa,bb), (ab,ba), (ab,bb), (ba,bb). The first and last are closed; the other four are retained. After composition all six are closed. The source operation represents the empty retained ledger by ("empty-One",), not by an additional source pair.

B. Both candidate inputs give the same image a and the same held fibre. The fibre specifies the possible predecessors; reconstruction of the particular run needs a retained predecessor label resolving the choice. For identity, each image has a singleton fibre, and reverse_record returns the unique source string directly. Follow uniqueRecovery and heldRecovery to compare the two cases.

C. First-occurrence image order is (b,a). The fibres are (b,(bb,ba)) and (a,(aa,ab)); reverse_record wraps each member list with "held-predecessor-labels". Both fibres remain non-singleton, so the map remains irreversible. Ordered records preserve more detail than merely reporting the two fibre sizes.
