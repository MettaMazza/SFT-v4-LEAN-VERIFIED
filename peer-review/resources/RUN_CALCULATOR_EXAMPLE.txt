RUN THE EXACT-RATIONAL CALCULATOR EXAMPLE
Maria Smith, Ernos Labs
Prepared with AI assistance, 18 November 2026.

START HERE
Download the script using the Raw/download control on its GitHub page:
https://github.com/MettaMazza/SFT-v4-LEAN-VERIFIED/blob/49dc14e68d15db15335c9941ffc7c42f32ab64d9/peer-review/resources/calculator-enclosure-example.py

Save it as calculator-enclosure-example.py. In a terminal opened in the folder containing that file, run:

python3 calculator-enclosure-example.py --x 1/5 --terms 1
python3 calculator-enclosure-example.py --x 1/5 --terms 2

The script uses Python 3's standard library: argparse and fractions.Fraction. No third-party Python package is required.

EXPECTED VALUES
For one term:
partial sum = 1/5
next-term magnitude = 1/375
rational endpoints = [74/375, 1/5]

For two terms:
partial sum = 74/375
next-term magnitude = 1/15625
rational endpoints = [74/375, 9253/46875]

These are exact fractions. The output also prints the branch used and interval width.

TRY A CHANGE
python3 calculator-enclosure-example.py --x 0.2 --terms 2

The decimal text 0.2 is parsed directly as Fraction, so it gives the same exact input as 1/5. If using the Python function directly, construct Fraction("0.2") or Fraction(1, 5); a binary floating-point argument is a different input representation.

The admitted x domain is 0 < x <= 1 and the term count must be a positive integer. For example:

python3 calculator-enclosure-example.py --x 0 --terms 2

This should report an input error and exit rather than produce endpoints. That rejection is intentional.

COMBINE THE BOUNDS FOR PI
The current script also has a --machin mode. Download this edition to use it:
https://github.com/MettaMazza/SFT-v4-LEAN-VERIFIED/blob/main/peer-review/resources/calculator-enclosure-example.py

python3 calculator-enclosure-example.py --machin --terms 2
python3 calculator-enclosure-example.py --machin --terms 8

This mode uses 1/5 and 1/239; --x is unused. The term count applies to each arctangent. It prints both rational intervals, the combined endpoints and their exact width. If those intervals are [a,b] and [c,d], the combination is [16*a-4*d,16*b-4*c]. Subtraction reverses which endpoint of the second interval is used.

With two terms in each sum, the combined endpoints are:
[306134117864772/97476408149875, 670143059704/213311234375]
The exact width is 12476980255684/12184551018734375.
Try changing the term count, and compare the widths without rounding to floats.
The angle identity and enclosure argument are in paper version 1.1, Section 5. This is an educational execution of the arithmetic, not a new Lean proof or a claim of independent review. Earlier pinned editions above retain their original single-arctangent interface.
