00:00–00:08 — Same result. Different execution.
Three expressions:
x + 1/3
1/3 + x
x + (1/6 + 1/6)
What should a comparison preserve?

00:08–00:16 — Compare the exact results.
At x = 2/3: all three return 1.
At x = 1/2: all three return 5/6.

00:16–00:24 — Now count the execution events.
x + 1/3: 6.
1/3 + x: 6.
x + (1/6 + 1/6): 10.
Horizontal bars visually encode these three counts.

00:24–00:32 — The observation makes a difference.
This comparison observes the exact result string.
Complete executions and separate resource ledgers retain the differences.
The first two expressions also evaluate their leaves in opposite orders.

00:32–00:40 — What would your application observe?
The result? Event order? Resource use?
