# Bulk-boundary correspondence and the primary Hall hierarchy

**Protection under every allowed finite deformation, exact reduced filling classes and oriented boundary counts**

## Abstract

A nontrivial bulk path class forces a supported, noncontractible boundary return on the original joint carrier. Any allowed path that removes that return would contract the retained bulk distinction; such compatible backscattering paths are absent within the declared gap. This protection persists after every generated finite allowed history. The proof uses the least equivalence generated by the original reversible, face-supported local moves and preserves the complete path class and boundary records. The primary Hall operation separately generates every reduced positive fraction with odd denominator up to its declared bound, in original denominator–numerator order. For distinct adjacent positive whole winding counts, the boundary operation returns their positive difference and retains the direction as a held orientation. This paper gives the full constructions, induction arguments, finite censuses and source-specific comparisons, with 1,024 candidate decisions and 493 distinct empty-axiom audited Lean declarations.

## 1. The complete generated path carrier

The original collective topological source characterizes order by invariance of the complete global path/adjacency class under every generated local deformation preserving connectivity and boundary records. The Materials invariant entry retains this construction at its declared integer-path-class observation boundary. Its carrier is a complete generated complex \(X\), consisting of the observed cell graph, a list of registered faces and a list of recorded boundary pairs. Every face node and edge belongs to the full graph. Paths are finite ordered lists of node labels, with validity checked against that graph.

For a path \(p\), write \(\partial p\) for its first and last labels, using the original optional endpoint representation for an empty list. An elementary deformation retains one registered face \(f\), two supported routes \(l,r\) in that face and surrounding paths \(u,v\). It changes

\[u\mathbin{+\!+}l\mathbin{+\!+}v
\longrightarrow
u\mathbin{+\!+}r\mathbin{+\!+}v.\]

Both complete routes must be valid in \(X\), and the complete endpoint records must agree:

\[\partial(u\mathbin{+\!+}l\mathbin{+\!+}v)
=\partial(u\mathbin{+\!+}r\mathbin{+\!+}v).\]

These are the explicit fields of `SFT.Physics.CollectiveTopological.Elementary.face`: actual face membership, both local support proofs, surrounding paths, boundary equality and both full-graph validity proofs. Reversal exchanges \(l\) with \(r\), exchanges their validity evidence and reverses the endpoint equality. It uses the same registered face. `elementaryReverse`, `elementarySourceValid`, `elementaryTargetValid` and `elementaryBoundary` establish these facts.

Define \(a\sim_X b\) by the original finite trace constructors:

1. Every valid path has an identity trace to itself.
2. If \(a\sim_X b\) and an elementary deformation changes \(b\) to \(c\), append that actual deformation to obtain \(a\sim_X c\).

The native `Trace` type contains exactly these constructors. A trace retains the complete generated history; it is not determined only by the endpoint pair.

## 2. Least generated equivalence and full class invariance

Composition is induction on the second history. If \(b\sim_X c\) is identity, composing it with \(a\sim_X b\) returns the first history. If its last step is \(d\to c\), compose the first history with the prior trace \(b\sim_X d\), then append that same step. This proves transitivity for all finite histories.

Reversal is induction on the history. The identity reverses to itself. For a trace ending with \(b\to c\), begin with the reversed elementary step \(c\to b\) and compose it with the reversed prior history. Source and target validity follow from the constructors, so each reversal begins on a valid path. Together with valid identity, these constructions establish the generated equivalence. They are `traceCompose` and `traceReverse`.

The relation is least among those containing the original identities and closed under the original append operation. Let \(R\) satisfy

\[\operatorname{valid}_X(p)\Rightarrow R(p,p),\]
\[R(p,q)\land\operatorname{Elementary}_X(q,r)\Rightarrow R(p,r).\]

Induction on a supplied trace \(a\sim_X b\) proves \(R(a,b)\): use the first hypothesis at identity and the second at each appended move. `leastGeneratedRelation` supplies this induction for every such relation \(R\). No additional path equivalence is inserted.

For a history \(h:a\sim_X b\) and any complete path \(q\),

\[a\sim_X q\quad\Longleftrightarrow\quad b\sim_X q.\]

In the forward direction compose \(h^{-1}:b\sim_X a\) with the given history from \(a\) to \(q\). In the reverse direction compose \(h\) with the given history from \(b\) to \(q\). Thus the complete classes agree extensionally:

\[[a]_X=[b]_X,\qquad [p]_X=\{q\mid p\sim_Xq\}.\]

`completeClassInvariant` proves the equivalence for every path \(q\). If \(a\) and \(q\) are in different classes, a permitted deformation history cannot make \(b\) equivalent to \(q\), since composition would contradict the original distinction. This is `differentClassRetained`.

Endpoint preservation is another induction on the same history. Identity gives equality immediately; at a successor, compose the previous endpoint equality with the actual elementary boundary equality. Hence \(\partial a=\partial b\), as proved by `traceBoundary`. A recorded boundary is an actual pair \((x,y)\) in \(X\)'s boundary list with \(\partial a=(x,y)\). Substituting the endpoint equality transports the same pair to \(b\), in both directions. `boundaryCorrespondence` therefore preserves the complete recorded boundary condition. Different endpoint records exclude a trace by `noBoundaryChangingTrace`.

The original registered square example has routes \((1,2,4)\) and \((1,3,4)\) in the same held face. Both are supported and have endpoints \((1,4)\). `registeredSquareDeformation` constructs their actual elementary move and `registeredSquareClass` appends it to a valid identity. The example instantiates the general generated relation; the preceding proofs quantify over all admitted faces, paths and finite histories.

## 4. Protection after every allowed history

Suppose that the boundary return could contract to the stationary path: \(q\sim_X[o]\). Composition with \(h\) would give

\[p\sim_Xq\sim_X[o],\]

contradicting the retained bulk distinction. Therefore \(q\not\sim_X[o]\). In particular \(q\ne[o]\), since the supported stationary path has its identity trace. These are `boundaryCannotContract` and `boundaryNontrivial`.

Now consider a proposed local removal within the declared gap,

\[g:q\sim_{X_G}[o].\]

Lifting \(g\) to \(X\) and composing with \(h\) would again give \(p\sim_X[o]\). `removalClosesBulkDistinction` proves this implication explicitly. Since the bulk class is nontrivial, `compatibleBackscatterAbsent` excludes such a gap history.

The same argument works after any allowed finite history, not only at the initial representative. Let \(q\sim_{X_G}q'\). Lift it to \(X\). Complete-class invariance transports noncontractibility, and endpoint preservation transports the return condition:

\[\partial q'=(o,o),\qquad q'\not\sim_X[o].\]

`protectionAfterEveryAllowedHistory` proves both conclusions for every supplied finite gap history. The result retains the original gap, face and boundary conditions. Its obstruction is the preserved nontrivial bulk class.

The complete carrier ledger also has exact finite extension. Define

\[\mathcal R(L)=\operatorname{map}(j\mapsto(j,q_j),L).\]

The singleton base is \(\mathcal R([j])=[(j,q_j)]\). List induction proves

\[\mathcal R(L\mathbin{+\!+}[j])=
\mathcal R(L)\mathbin{+\!+}[(j,q_j)].\]

At the empty prefix this is the singleton equation; at a retained head, both sides prepend its complete joint record to the induction hypothesis. `ProtectedBoundary.base` and `successor` retain the whole complex, joint history, bulk distinction, gap faces and conditions in every row.

## 5. Exact primary Hall hierarchy

The Hall successor source retains whole winding classes together with a separately bounded primary hierarchy of reduced positive odd-denominator parts on its gapped oriented two-generator material carrier. For a positive bound \(M\), the source visits denominators

\[d=1,3,5,\ldots\leq M.\]

Their number is \(K=\lfloor(M+1)/2\rfloor\), so write \(d_k=2k+1\) for \(0\leq k<K\). For each denominator it visits numerators in ascending order \(1\leq n\leq d_k\) and retains exactly \(\gcd(n,d_k)=1\). Define

\[N_d=[n/d\mid 1\leq n\leq d,\ \gcd(n,d)=1],\]
\[H_M=N_1\mathbin{+\!+}N_3\mathbin{+\!+}\cdots
\mathbin{+\!+}N_{2K-1}.\]

This is the exact ordered source enumeration. The guard already reduces each fraction, and its bounds give \(0<n/d\leq1\). The native `HallPrimary.ReducedPart` retains numerator positivity, denominator positivity, the at-most-One inequality and coprimality as fields. `reducedPositiveBounded` returns their conjunction.

The numerator recursion is explicit. Starting with an empty prefix, advance from \(n\) to \(n+1\). If \(\gcd(n+1,d)=1\), append exactly \((n+1)/d\); otherwise retain the prefix. Induction therefore gives every accepted numerator in original order and no rejected numerator. The denominator recursion appends the next complete numerator list:

\[O_0=[],\qquad O_{k+1}=O_k\mathbin{+\!+}N_{2k+1},\qquad H_M=O_K.\]

`numeratorParts`, `oddParts`, `primaryClasses` and `oddSuccessor` implement this construction. For any original odd \(d\leq M\), its index \((d-1)/2\) occurs in the denominator recursion; every positive bounded coprime numerator occurs in that denominator's recursion. Conversely every returned row comes from those two recursions and their guard. Thus the construction exhausts its declared primary hierarchy while preserving source order.

## 6. Boundary recurrence count and held orientation

For distinct adjacent positive whole winding counts \(a,b\), the original boundary operation returns

\[c=\max(a,b)-\min(a,b),\]

with orientation

\[\epsilon=\begin{cases}
\text{first-to-second},&a<b,\\
\text{second-to-first},&b<a.
\end{cases}\]

If \(a<b\), strict order gives \(b-a>0\), so the first branch returns positive count \(b-a\). Otherwise, inequality of the inputs and total order give \(b<a\), hence \(a-b>0\). The direction is the held label with family `bulk-order`; it is not encoded by a signed proof quantity. `BoundaryEdgeCount.firstGapPositive` and `secondGapPositive` prove the two positive branches using the existing exact natural-number subtraction result.

The original equality case is rejected with the exact error `edge count requires distinct adjacent winding classes`. `equalRejected` proves that branch of the native operation. The successful certificate contains both the positive count object and the full orientation object. For the original witness \((a,b)=(5,2)\),

\[c=5-2=3,\qquad\epsilon=\text{second-to-first}.\]

`originalWitnessPassed` proves the registered count test; the complete source-output comparison retains both returned fields. Swapping the two distinct inputs preserves the positive difference and exchanges their two order cases. The difference counts the intervening whole winding levels: in the \(a<b\) branch they are \(a+1,\ldots,b\), which has \(b-a\) members; the reverse ordering gives the same argument with \(a,b\) exchanged.

The pinned full comparison covers 1,028 positive pairs, including 33 equal-input rejections, both successful fields and exact error text. The release reproduction evaluates all \(33^2=1089\) pairs with both counts from 1 through 33, preserving 33 equality rejections and all 1,056 successful two-field records. These explicit cases accompany the general positivity and branch proofs.
