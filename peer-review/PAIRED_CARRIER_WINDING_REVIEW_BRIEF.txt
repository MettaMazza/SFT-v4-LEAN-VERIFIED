THE ORIGINAL OPERATION
A FoldQuantumState has nonempty support with distinct branch words and a distinct phase cycle C of length d >= 2. Every branch phase belongs to C. The original phase_action requires a nonempty successor trace. With trace length m, it preserves every branch word and shifts each selected phase index i to (i+m) mod d, keeping branch order and the entire cycle.

WORK THROUGH THE RETURN ARGUMENT
Take a distinct cycle C and a phase actually found at index i. Finding that phase establishes i < d and d > 0. If shifting by m returns the same phase, distinct cycle labels imply
  (i+m) mod d = i.
Quotient/remainder decomposition then gives
  i+m = d*((i+m)/d) + i.
Cancel i: m is a whole multiple of d. Conversely, adding d*n leaves the remainder at i, so a whole winding returns the selected phase. Thus:
  shiftPhase C m phase = some phase
  iff there exists n : Nat with m = d*n.

In SFT.Materials.FluxWinding, inspect:

- wholeWindingReturns
- returnExactlyWholeWinding

The general remainder theorem takes a natural count, including zero as the structural empty-count case. The original quantum phase_action retains its nonempty-trace requirement and cycle length at least two. Check these domains explicitly when moving between the lemma and operation.

FROM ACTUAL PATH TO COMPUTED CLASS
Each loop supplies a valid closed graph path, distinct cycle, selected phase and return along its actual adjacent-pair transition list. Set
  m = length(adjacentPairs path)
  w = m / d.
The return theorem gives m=d*n; positive d makes division yield w=n. The result is m=d*w. The winding output is computed from the retained path and cycle.

For a three-label cycle, consider transition counts 1, 2, 3 and 6. Counts 1 and 2 do not return a selected phase; 3 returns with winding 1; 6 returns with winding 2. Here m counts adjacent transitions, not path vertices. These are reading examples of the quantified argument.
