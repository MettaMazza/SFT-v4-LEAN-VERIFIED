START WITH A PATH EXTENSION
A configuration node retains its molecular carrier, coordinate label, height and record identity. A path is a nonempty ordered list with the same carrier throughout. Heights retain the original positive-rational or structural EmptyOne representation and constructor decisions.

The list [a,b,c,d] has interior triples (a,b,c) and (b,c,d). Appending e preserves both in their original order and adds (c,d,e). The native proof quantifies over arbitrary finite tails:
  SFT.Chemistry.ConfigurationOrder.priorComparisonsRetained
  SFT.Chemistry.ConfigurationOrder.completeComparisonCount
  SFT.Chemistry.ConfigurationOrder.exactlyOneNewComparison
The first two use induction on the actual tail; the extension count follows the exact triple-count equation. successorRetainsNodes separately retains the previous node list. The number of interior triples is max(n-2,0), not the number of nodes.

READ THE CORE DECISION BRANCHES
In the original ConfigurationPath.local_minimum and local_barrier operations, a requested position must have both neighbours inside the retained path. Endpoints and out-of-range signed indices are rejected.

For three positive rational heights, a basin requires the centre strictly below both neighbours; a barrier requires it strictly above both. Ratios compare by exact cross-products.

The structural branches are explicit. An EmptyOne centre is a basin when both neighbours are nonempty. A positive centre with an EmptyOne neighbour is not a basin. In the core barrier operation, a nonempty centre with either EmptyOne neighbour enters the structural barrier branch without additionally comparing the other neighbour's positive height. Read this original branch order, rather than silently substituting the ratio-only test for every case.

Native minimumTriple and barrierTriple preserve these operations. positiveBasin, positiveBarrier and structuralBasin expose their corresponding equations. The source's canonical singleton and other EmptyOne instances also retain distinct runtime outcomes in the native representation; consult Section 2 and the complete source.

FOLLOW THE COMPLETE OBSERVATION SEPARATELY
The pinned ethanol observation contains two torsion paths, each with 25 rows from 0 to 360 degrees in 15-degree steps. The observation verifies equal initial and terminal heights. It retains all rows, then removes the terminal copy only for cyclic classification, leaving 24 distinct positions per path.

The original validation converts the kJ/mol inscriptions into exact fractions and compares each centre with neighbours at indices (i-1) mod24 and (i+1) mod24. This is the observation's cyclic strict-comparison operation. It remains distinct from the core mixed structural branch above.
